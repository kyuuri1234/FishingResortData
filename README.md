# ファミリーフィッシング 解析データ

魚、釣り場、ルアー、トローリング航路から値を引ける[検索ページ](index.html)がある。

Wii『ファミリーフィッシング』(海外版 *Fishing Resort*) のプログラムとゲームデータを解析して分かった、遊ぶ人向けの情報をまとめたものである。


## 場所と湧き

| 知りたいこと | ページ |
|---|---|
| ある魚はどこで釣れるか | [検索ページ](index.html) |
| ある釣り場に何がどれだけ湧くか | [エリアの一覧と地図](docs/maps.md) |
| 確率の読み方、時間帯、魚の数の上限 | [魚の湧き方](docs/spawn.md) |
| 魚が生まれる経路、補充、消える条件 | [湧き経路](docs/spawn-paths.md) |
| 魚影が見えない理由 | [魚影](docs/shadow.md) |
| 天気の種類と出やすさ | [天気](docs/weather.md) |
| ゲーム内の時間、大会とツアーの日程 | [時間と予定](docs/calendar.md) |

ゲームのファイルがあれば、表の数値は [tools/](tools/README.md) で再生成して確かめられる。

## 注意
解析により得られた情報を多量に含みます。こういったことが苦手な場合は見ないほうがいいでしょう。

一部、実機で検証できていない箇所を含みます。間違いがあった場合、issueなどからご指摘いただけると幸いです。

AI生成の文章を含みます。

非公式の資料で、ゲームの権利者とは無関係です。
対象ROMは日本語版 (ディスクID S22JAF、リビジョン1) です。
ゲームのファイル、画像、音声等を含みません。
