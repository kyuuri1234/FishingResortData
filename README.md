# ファミリーフィッシング 解析データ

Wii『ファミリーフィッシング』(海外版 *Fishing Resort*) のプログラムとゲームデータを解析して分かった、遊ぶ人向けの情報をまとめたものである。

非公式の資料で、ゲームの権利者とは関係ない。
対象は日本語版 (ディスクID S22JAF、リビジョン1) である。
ゲームのファイルや画像は含んでいない。
地図は、ゲームの当たり判定の形から描き直したものである。
