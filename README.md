## 注意

解析により得られた情報を多量に含みます。
こういったことが苦手な場合は見ないほうがいいでしょう。

一部、実機で検証できていない箇所を含みます。
間違いがあった場合、issueなどからご指摘いただけると幸いです。
正確性については気をつけていますが、何ら保証はできません。

AI生成の文章を含みます。
全て読み返し、不自然でない表現に直すよう努めていますが、カスの文章を含む可能性はあります。

非公式の資料で、ゲームの権利者とは無関係です。
対象ROMは日本語版 (ディスクID S22JAF、リビジョン1) です。
ゲームのファイル、画像、音声等を含みません。
