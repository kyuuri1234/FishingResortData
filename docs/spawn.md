# 魚の湧き方

[目次](../README.md)

## 確率の読み方

釣り場の水面は「スポット」という長方形に分かれていて、スポットごとに出現表がある。
魚が1匹湧くたびに、そのスポットの表から抽選で種類を決める。
[検索ページ](../index.html)の確率は、この1回の抽選でその魚が選ばれる確率である。

確率は「重み ÷ その表の重みの合計」である。
重み2の魚は、重み1の魚のちょうど2倍選ばれる。
スポットの広さは抽選に関係しない。

## 時間帯

出現表には朝・昼・夕・夜の値があるが、実際に使われる表では4つの値が全て同じである。
時間帯で湧く魚の種類や割合は変わらない。

時間帯で変わるのは、スポットに同時にいられる魚の数の上限である。
全468スポットのうち205スポットは時間帯で上限が変わり、そのうち204スポットは朝が最も多く、203スポットは昼が最も少ない。
たとえばパナス・ジャングルのスポット9は、朝20匹、昼12匹、夕14匹、夜16匹である。
これらのスポットの朝の上限は昼の1.33倍 (中央値) で、最大で2.5倍である。

| 時間帯 | ゲーム内の時刻 |
|---|---|
| 朝 | 6:00〜11:59 |
| 昼 | 12:00〜15:59 |
| 夕 | 16:00〜17:59 |
| 夜 | 18:00〜翌5:59 |

## 確率どおりにならない場面

- 浅い場所: 水深が体長の4分の1より浅い場所には湧かない。
  種類を選んだあとで判定するので、浅いスポットでは大きな魚が表より少なくなる。
  ただし影響は小さく、地形から計算すると、スポットと魚の組み合わせ4,012通りのうち、確率が1ポイント以上変わるのは11通りで、最大でも3.8ポイントである。
  スポットごとの水深は [spot_depth.csv](../data/spot_depth.csv) にある。
- コピー湧き: 周りにいる魚の種類から選ぶので、その場所の表にいない魚がかかることがある ([湧き方の種類](spawn-paths.md#コピー湧き))。
