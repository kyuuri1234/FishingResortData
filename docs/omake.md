# おまけ
## 没データ
このゲームにはいくつか没データが残っている。多くはゲーム内からは見えないようになっている。

### 欠番（ニシキゴイ）
魚id 26番 欠番（ニシキゴイ） という魚がデータ上存在する。欠番まで含めて名前である。

どこにも出現しない。
外部ツールにより強制的に出現させた際は魚影が確認できず、釣ってみるとアジが釣れたことになった。

### TestStage
TestStageという没エリアがある。入る経路は塞がれており、製品版では入れない。

魚の出現表などが設定されているが、水がないので湧かない。

強引に入ると、青と白の市松模様が一面に広がる没エリア感がすごい場所になっている。

釣り竿を構えられるが、水がないのでウキが地面に落ちてしまう。

### トローリング用魚のパラメータ
トローリングの魚にも通常の魚と同様のパラメータが存在しており、出現さえさせることができれば
普通に釣ることができる。

外部ツールにより、実際にシイラとダンクルオステウスを出現させて釣ることができた。

シイラは簡単に釣れたが、ダンクルオステウスはハイネリア級の強さだった。パラメータもハイネリア
と同等に設定されている。

なお、釣果画面では3Dモデルの角度がバグり、尻尾を斜め上に向ける体制になる。

### Wholeisland
外海のマップには、トロピカル/テンパレート/フリジットとは別に、魚の出現表が設定されている。
ただし、一切読まれないので没データである。

ワカサギ、ナマズ、ホオジロザメなどが設定されている。
淡水、海水、トローリングが入り混じる出現設定となっており、統一感がまったくない。

このエリアの魚には、時間帯により体長が少し小さくなる設定が組み込まれている。
例えば、このエリアのスタージオンは0.98倍、昼0.94倍、といった具合である。

このような設定はこのエリア特有で、実際のデータでは全ての魚の体長
が時間帯によらず1.0倍として処理されている。
