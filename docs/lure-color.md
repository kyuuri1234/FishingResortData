# ルアーの色と好み

[目次](../README.md)

ルアーの色は、魚の[興味](bite.md#興味)が溜まる速さを変える。
魚ごとに「好きな色」があり、ルアーの2色のうち好きな色に近いほうで倍率が決まる。

## 使い方

1. [魚の一覧](fish-table.md)で、狙う魚の「基準色」を調べる。
2. その日の天気 (空の見た目) を確かめる ([天気](weather.md))。
3. 下の[おすすめの色の表](#基準色と天気ごとのおすすめの色)から、色の組を選ぶ。
4. [色の組とルアーの表](#色の組とルアー)から、その組のルアーを探す。
   ルアーの[系統と体長の範囲](#ルアーの系統と体長)も合わせて確かめる。

ゲームの画面に番号は出ない。

## 好きな色の決まり方

魚の好きな色は、魚が湧いたときに1匹ずつ決まる。
魚の種類ごとに決まった基準色に、抽選で決まる0〜6を足した色になる。
足すだけなので、番号が減る向きにはずれない。
12を超えたら1に戻る。

足す数の確率は天気で決まる。
単位は%である。

| 薄曇り | 29.4 | 17.6 | 35.3 | 11.8 | 5.9 | - | - |
| 曇り | 31.2 | 6.2 | - | 12.5 | 37.5 | 12.5 | - |
| 厚い曇り | 20.0 | 6.7 | - | - | - | 20.0 | 53.3 |

## 色の倍率

ルアーの2色のそれぞれについて、好きな色との番号の差を求め、小さいほうを使う。
番号の差は輪の上で数えるので、最大は6である (12と1の差は1)。

| 番号の差 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|--:|--:|--:|--:|--:|--:|--:|
| 2色のルアー | 0.8 | 0.6 | 0.4 | 0.2 | 0 | 0 | 0 |
| 1色のルアー | 1.0 | 0.8 | 0.6 | 0.4 | 0.2 | 0 | 0 |

倍率が0の魚は、そのルアーへの興味がまったく溜まらない。
1色のルアーは次の3本だけである: ハンブル オレンジ、ゼブラクランク オレンジ、Hamstring OR。

## 基準色と天気ごとのおすすめの色

天気ごとの好きな色の確率で倍率を平均し、その値 (倍率の期待値) が最も高い色の組を選んだ。
括弧の中が期待値である。
「7+9」は色7と色9の組を表す。
「5のみ」「7のみ」は1色のルアーである。
同じ値の組が3つを超えるときは、はじめの3つだけを書いている。

この表は色だけで選んだものである。
実際には、魚が反応する系統と体長の範囲に合うルアーの中から選ぶ ([ルアーの系統と体長](#ルアーの系統と体長))。

## 機構

ルアーには3種類の機構があり、魚にも好む機構がある。
名前はこの資料の呼び名である。

一致しなくても罰はない。
魚の好む機構は[魚の一覧](fish-table.md)の「機構」の列にある。

## ルアーの系統と体長

ルアーは色の前に、2つの条件で魚をふるいにかける。
どちらかを満たさない魚は、色が合っていても反応しない。

- **系統**: 魚ごとに反応するルアーの系統が決まっている ([魚の一覧](fish-table.md)の「反応するルアー」)。
  「反応率」は、魚が系統の合うルアーの候補に入るときに、反応する確率である。
  外れると興味が0に戻るので、10%の魚はなかなか寄ってこない。
  反応率100%の魚は、興味の溜まり方が2倍である。
- **体長**: ルアーごとに反応する体長の範囲がある。
  判定は種類ではなくその魚の体長で行われる。
  範囲の両端の体長は含む。

ルアーの説明文に書かれた対象サイズと、実際の範囲は一部で違う。
下の表は実際の判定の範囲である。
魚ごとの一覧は[魚ごとの使えるルアー](fish-lures.md)にある。

## 場所の補正

同じルアーを別の魚がつついている間だけ、その魚が湧いたスポットの[エサの補正](bait.md#場所による補正)の値が、色の番号の差から引かれる。
効く場面が限られるので、上の表には入れていない。
