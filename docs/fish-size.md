# 魚のサイズとランク

[目次](../README.md)

## 決まり方

魚の体長は、魚が湧いたときに1回だけ決まる。
釣ったあとに決め直されることはない。

1. 6つのサイズ帯から1つを抽選する。
2. その帯の範囲の中から、0.01cm刻みで均等に1つの値を選ぶ。

帯の範囲は、魚ごとの基準サイズに次の倍率を掛けた値である。

| サイズ帯 | 基準サイズ比 | ランク |
|---|--:|:-:|
| 帯0 | 1.25〜1.30倍 | S |
| 帯1 | 1.20〜1.25倍 | A |
| 帯2 | 1.10〜1.20倍 | B |
| 帯3 | 1.00〜1.10倍 | C |
| 帯4 | 0.90〜1.00倍 | D |
| 帯5 | 0.85〜0.90倍 | E |

実際の値は倍率からごくわずかに引いた数で、たとえば基準20cmのアジは16.98〜25.98cmである。
そこからさらに0.01cm単位に切り捨てるので、最大の値は基準×1.299を切り捨てた値になる。
ブリ (基準100cm) の最大は129.89cm、アナゴ (基準50cm) の最大は64.94cmである。

ラージマウスバスとピーコックバスだけは、倍率が別に調整されている。

## ランクの境目

ゲームの中にはランクを判定する処理が2つある。

- 釣った直後の結果画面の判定: 体長と境目をそれぞれ100倍して切り捨てた整数で比べる。
- 図鑑の判定: 体長と境目をそのまま比べる。

小数の計算の誤差のために、結果画面の境目は図鑑より0.01cm低くなることがある。

<!-- table:size-diff -->
233件のうち104件で、Sの境目が0.01cm違う。
<!-- /table -->

たとえばロングノーズガーは、結果画面では149.87cmからS、図鑑では149.88cmからSである。
この0.01cmにちょうど当たると、結果画面はSで図鑑はAになる。
