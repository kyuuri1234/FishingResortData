# 時間と予定

[目次](../README.md)

## ゲーム内の時間

ゲーム内の1日は現実の30分で、1時間は75秒である。
時計は24:00で止まる。

ファイト中は、14:00より前なら同じ速さで進み、14:00より後なら10分の1の速さになる。

会話、メニュー、場面の切り替え、ミニゲームの間は時計が止まる。
釣りの操作そのものでは止まらない。

## 28日の周期

ツアーや大会の予定は、月曜始まりの4週間を繰り返す。
第1週は、ゲームを新しく始めた週である。
始めた日の曜日は、そのときの Wii 本体の日付で決まる。

## トローリングツアー

南海岸は毎週の土日に出る。
西海岸は第1・3週、北海岸は第2・4週の毎日に出る。
NPCの「トローリングは週によって行き先が変わる」は、この西と北の入れ替わりのことである。

| ツアー | 海域 |
|---|---|
| 南海岸 | トロピカル (熱帯) |
| 西海岸 | テンパレート (温帯) |
| 北海岸 | フリジッド (寒帯) |
