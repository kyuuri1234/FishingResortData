# 魚影

[目次](../README.md)

魚が寄って食いつくかどうかは魚の位置だけで決まり、魚影が見えているかどうかは関係ない。

## 透明な魚

魚は湧いたときに次の確率で透明になり、ファイトに入るまで魚影が出ない。

| 魚 | 透明になる確率 |
|---|--:|
| 通常の湧きの魚 | 30% |
| ゴミ10種 | 100% |
| ウキに湧いた魚 | 100% |
| 外海の魚 | 100% |
| ワカサギ、結果画面の2匹 | 0% |

ウキに湧いた魚については[湧き経路](spawn-paths.md#ウキに湧く魚)を参照。

ゴミ10種は次のとおりである。

<!-- table:junk-list -->
ありきたりな流木、もさもさした海藻、ごてごてした水草、ふさふさな水草、アンモナイトの化石、三葉虫の化石、りっぱな流木、ふつうの流木、まっすぐな流木、ふつうの海藻
<!-- /table -->

透明かどうかは湧いたときに決まり、その魚が消えるまで変わらない。

## 距離

魚影の距離の基準はプレイヤーの位置で、ウキの位置ではない。

| プレイヤーからの水平距離 | 魚影 |
|---|---|
| 20m以内 | フェードインして見える |
| 20〜60m | フェードアウトして消える |
| 60mより遠い | すぐ消える |
| 80mより遠い | 魚そのものが消える |

## 水面ではねる魚

はねるのは次の条件をすべて満たす魚である。

- 透明でない。
- ゴミでない。
- 体長が100cm未満。
- 魚影が出ている。
- プレイヤーから15mより遠い。
- 誰もファイトしていない。
- 同時にはねている魚が2匹未満。

魚影はふつうプレイヤーから20m以内でしか出ないので、はねるのはプレイヤーから15〜20mの輪の中にいる魚である。

はねるかどうかの抽選は1匹あたり平均1秒に1回で、当たる確率は10%である。
湧いた魚は、最初に当たったときにはねる。
はねたあとは、さらに25〜33回当たらないと次にはねない。
条件を満たし続けても、次にはねるまで平均4〜5分かかる。

はねている間は、プレイヤーからの距離に関係なく魚影が出る。
はねた魚は、溜めていた[興味](bite.md#興味)を失い、仕掛けを探すところからやり直す。
