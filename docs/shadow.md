# 魚影

[目次](../README.md)

## 透明な魚

魚は湧いたときに次の確率で透明になり、ファイトに入るまで魚影が出ない。

| 魚 | 透明になる確率 |
|---|--:|
| 通常の湧きの魚 | 30% |
| ゴミ10種 | 100% |
| ウキに湧いた魚 | 100% |
| 外海の魚 | 100% |
| ワカサギ、結果画面の2匹 | 0% |

ウキに湧いた魚については[湧き方の種類](spawn-paths.md#ウキに湧く魚)を参照。

ゴミ10種は次のとおりである。

<!-- table:junk-list -->
ありきたりな流木、もさもさした海藻、ごてごてした水草、ふさふさな水草、アンモナイトの化石、三葉虫の化石、りっぱな流木、ふつうの流木、まっすぐな流木、ふつうの海藻
<!-- /table -->

透明かどうかは湧いたときに決定され、その魚が消えるまで変わらない。

## 距離

プレイヤーからの距離によって、魚影の処理が異なる。

| プレイヤーからの水平距離 | 魚影 |
|---|---|
| 20m以内 | フェードインして見える |
| 20mより遠い | フェードアウトして消える |
| 80mより遠い | 魚そのものが消える |

## 水面で跳ねる魚

次の条件を全て満たす魚は、水面で跳ねる。

- 体長が100cm未満。
- 魚影が出ている。
- プレイヤーから15mより遠い。
- 同時に跳ねている魚が2匹未満。

個体ごとに平均1秒に1回、跳ねるかどうかの抽選が行われる。
抽選が当たる確率は10%である。

湧いた魚は、条件を満たしており、かつ抽選が最初に当たったときに跳ねる。
一度跳ねた後は、さらに25〜33回当たるまで跳ねない。

跳ねている間は、プレイヤーからの距離に関係なく魚影が出る。
跳ねた魚は、溜めていた[興味](bite.md#興味)がリセットされる。
