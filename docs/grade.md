# 魚の格付け

[目次](../README.md)

魚には種類ごとに0〜5の格付けがある。
この資料での呼び名で、画面には出ない。
魚ごとの格付けは[魚の一覧](fish-table.md)にある。

待ちとつつく時間は[魚が寄って食いつくまで](bite.md)、逃げる距離は[かかった直後の逃げ](fight.md#かかった直後の逃げ)、レーダーは[外海のレーダー](trolling.md#外海のレーダー)にある。

格付け0は流木・水草・海藻である。
化石2種は格付け2である。

ポイントは魚ごとの値で、格付けとは別のデータである。
格付けが高い魚ほどポイントが高い傾向はあるが、範囲は重なっていて、ゲームは格付けからポイントを計算していない。

経験値はゲームの画面に出ない値で、累計で称号が決まる ([称号と経験値](fish-size.md#称号と経験値))。
魚ごとの値だが、表のとおり格付けと対応していて、例外は100のポリプテルスだけである。

どの魚が湧くかの抽選に、格付けは使われない。

## 表のほかに効く場面

- ウキに湧く魚: 格付け2以下の魚だけが候補である ([湧き経路](spawn-paths.md#ウキに湧く魚))。
- 結果画面の曲: 格付け4以上なら必ず特別な曲である ([ファイト](fight.md#釣り上げたあと))。
- 受付嬢の話題: 格付け4以上の魚の話は、釣った数やランクの話より優先される ([受付嬢の話題](reception.md))。
  釣った直後に近くのNPCが声をかけるときも、格付け4以上の魚には専用のセリフがある。
