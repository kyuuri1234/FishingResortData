# 湧き経路

[目次](../README.md)

魚が生まれる経路は次の6つである。
「透明」については ([魚影](shadow.md))を参照のこと。

| 経路 | 種類の決め方 | 場所 | 透明 | [エサの場所補正](bait.md#場所による補正) |
|---|---|---|---|---|
| 通常の湧き | スポットの出現表の抽選 | スポットの長方形の中 | 30% | スポットの値 |
| ウキに湧く魚 | 周りにいる魚の種類から均等に | ウキの位置 | 100% | なし |
| 外海の湧き | 区画の出現表の抽選 | 船の周り ±30m | 100% | スポットの値 |
| トローリング | 航路の表の抽選 | - | - | - |
| ワカサギ | ワカサギ専用 | - | - | - |
| 釣果画面の2匹 | 釣った魚と同じ | - | - | - |

釣果画面の2匹については後述。

どの経路でも、体長は同じ処理で決まる ([魚のサイズとランク](fish-size.md))。

## 通常の湧き

1. プレイヤーがスポットの長方形の周囲60m以内にいなければ、そのスポットでは湧かない。
2. 範囲に入った瞬間に、上限の3分の2の魚をまとめて湧かせる。
3. 残りは、全スポットを合わせて1フレームに1匹ずつ湧く。

1匹が湧くときのプロセスは次のとおりである。

1. 出現表の抽選で種類を決める。
   未解放の魚に当たったら、17回まで引き直す。
2. 体長を決める。
3. 長方形の中の場所をランダムに選ぶ。
4. 深さを水面から水深の2割の位置にする。
5. 次の場所なら湧きを中止する。
   - 水の外
   - 水深が体長の4分の1未満の場所(2mの魚なら水深0.5m未満)
   - プレイヤーからの水平距離が80m以上
   - プレイヤーの後ろの半径30m,内角120度の扇形の内側かつプレイヤーが釣りをしている
6. 魚を作り、透明かどうかを抽選する ([魚影](shadow.md))。

スポットのデータには深さの重みもあり、水深の2割・5割・8割や、2〜8割の間のランダムな深さが設定されている。
しかし抽選の書き方のために必ず2割が選ばれるので、魚は水深の2割の深さにしか湧かない。

範囲から出て入り直すと、また上限の3分の2までまとめて湧く。

## 補充の速さ

スポットの魚が上限より少なければ、ふだんは途切れず補充される。

そのスポットの魚が仕掛けをつつき始めると、そこから60秒の間だけ補充がゆっくりになる。
この間は、[検索ページ](../index.html)のスポットに出る「補充間隔」がたつごとに1匹ずつ補充される。
別の魚がつつき始めると、また60秒に戻る。

魚が上限まで詰まっていると、「補充間隔」の2倍の時間がたつごとに、いちばん古い魚が1匹フェードアウトして消え、空いた分がすぐ補充される。

代表的な補充間隔は、トゥマン・パラダイスビーチが6秒、ジャングルが42秒、ドゥアリブ・レイクとティドゥール・リバーが36秒、サフィーア・ケイブが120秒である。
全スポットの値は [spots.csv](../data/spots.csv) の `refill_sec` にある。

同時に存在できる魚は全部で320匹である。

## ウキに湧く魚

ウキが水面に落ち着いてから18〜22秒たっても、ウキに食いついている魚がいないと、ウキの位置に魚が1匹湧く。
投げ直すまで、次は湧かない。

種類は、プレイヤーから80m以内にいる魚の中から以下の条件を満たす魚を除いてランダムに選ぶ。

- グレード3以上の魚種
- LLサイズの魚
- 未解禁の魚

選び方は種類ごとに均等である。
1匹しかいない種類も、30匹いる種類も同じ確率である。
- 候補がないときは、周りの魚の中でグレードが低く小さい魚になる。
- 周りに魚がいなければアジになる。

この魚は必ず透明で、エサの場所補正もかからない。
スポットに属さないので、スポットの上限には数えない。

湧いたあとはすぐ食いつかず、いったん止まってから泳いでウキに来る。
そのため、この魚がかかるのは投げてから1分前後たってからである。

場所の出現表にない魚が釣れるのは、この湧き方のためである。
エメラルド・マーシュでピラニアやパクーが釣れるのが代表的な例である。
マーシュの東岸から東側の川のスポットまでは60m前後なので、マーシュにいる間も川の魚が周りに残る。
その魚の種類がウキの位置に湧く。
川の釣り場からマーシュのスポットまでは90m以上あるので、逆は起きない。

## 外海の湧き

船の周り ±30m、クルーザーの位置の3〜5m下にスポーンする。魚種はクルーザーの位置によって決まる。

船から30m以上離れた魚は消える。

外海の魚の魚影は必ず透明となる。甲板から魚が一切確認できないのはこのためであり、魚影自体は内部では存在している。

なお、レーダーにはこの魚の一部が点として映る ([外海のレーダー](trolling.md#外海のレーダー))。

## 結果画面の2匹

魚を釣り上げた瞬間、釣った魚は消えて、結果画面の演出用に同じ種類の魚が2匹作られる。

- 1匹は釣った魚の複製で、体長・ランク・[経験値](fish-size.md#称号と経験値)を受け継ぐ。
  釣果画面に映るのはこの魚である。すなわち、ファイトをする魚と釣果画面の魚は別個体である。
- もう1匹はその種類の基準サイズの魚で、画面には映らない。

釣り上げの動きは基準サイズの魚に合わせて作られていて、そのまま拡大すると手や糸の位置から魚がずれてしまう。
そこで、基準サイズの魚に同じ動きをさせて体の位置を測り、映す魚をその位置に合わせている。

このとき、魚の見た目の大きさは、基準サイズとの差を持ち方に応じて縮めた値になる。

| 持ち方 | 基準サイズとの差の反映 |
|---|--:|
| 糸をつかむ | 100% |
| 手のひら | 50% |
| 両手 | 50% (タチウオは25%) |
| 水中 | 20% |

たとえば、両手で持つ基準100cmのキングサーモンが120cmなら、110cmの大きさに見える。
魚ごとの持ち方は [fish.csv](../data/fish.csv) の `hold` にある。
